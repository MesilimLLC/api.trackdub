Unified entry points: `npm run dev|build|deploy` for the main API, `npm run dev:activation|deploy:activation|deploy:activation:staging` for the activation worker, `npm run test:all` to run both suites, `npm run db:migrate:{local,remote}` for the API D1, and the corresponding `db:migrate:activation:{local,remote}` commands for the activation D1. Migration IDs are hard-coded per target in the scripts.
