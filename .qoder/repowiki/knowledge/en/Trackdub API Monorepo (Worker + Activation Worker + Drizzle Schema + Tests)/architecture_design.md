Two independent Cloudflare Workers share this repo: the main worker (`src/index.ts`, Hono app with Better Auth, D1, R2) and the standalone activation worker under `activation/`. Each has its own Wrangler config (`wrangler.jsonc` vs `wrangler.docs-rag.jsonc` / `wrangler.activation.*.jsonc`) and Drizzle Kit config (`drizzle.config.ts` vs `drizzle-activation.config.ts`), but they point at the same `drizzle/` migration directory for the main DB and `drizzle-activation/` for the activation DB. The root `package.json` is the single entry point: scripts delegate to `cf dev`/`cf build`/`cf deploy` for the main worker and `wrangler dev/deploy --config wrangler.<env>.jsonc` for docs-rag and activation variants, while `vitest.config.ts` drives tests against the main worker's in-memory D1/R2 and `vitest.activation.config.ts` drives the activation worker's tests via `@cloudflare/vitest-pool-workers`. Both workers are typed via `@cloudflare/workers-types` and validated through Zod; `bun run test:all` runs both suites sequentially.
