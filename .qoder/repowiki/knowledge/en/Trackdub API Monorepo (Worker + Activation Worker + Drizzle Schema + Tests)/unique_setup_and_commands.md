Single `bun install` at the repo root; local dev uses `cp .dev.vars.example .dev.vars`, then `bun run db:generate && bun run db:migrate:local && bun run dev`. Migrations are applied per-worker: `db:migrate:remote` for the main D1 (`073c0238-...`) and `db:migrate:activation:{local,remote,staging:remote}` for the activation D1 (`f95337b1-...` / `d694b5d5-...`). Docs-RAG pin generation is gated by `predev:docs-rag` and `predeploy:docs-rag` hooks running `scripts/gen-docs-rag-pin.mjs` before either `dev:docs-rag` or `deploy:docs-rag`. Full test harness is `bun run test:all`.
